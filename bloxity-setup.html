Hop on your pogo stick and never stop bouncing! Every bounce gives you Power, Power levels you up, and every level adds +2.5 Jump Power. Bounce up the giant Rainbow Stairs out at sea (10, 25, 45 ... 3,549 STUD) and claim the Wins pad on every step. Spend Wins on 14 pogo skins up to x300 Power, train on trampolines up to x250, grab Power Gems, rebirth for bigger boosts and race your friends to the top of the leaderboards.

4. Server environment (hosting.bloxity.io → app jump-pogo)

App id
jump-pogo
LEGION_WEBHOOK_SECRET
Same secret as the webhook. Setting it switches the game from demo mode to real Bux.
SAVE_SECRET
Any long random string (signs players’ progress backups)
MONGODB_URI
Provided by Legion automatically; progress is stored in MongoDB
BLOXITY_GAME_ID
Optional: the game id, to report profile stats
BLOXITY_REPORT_TOKEN
Optional: stats report token from Manage Games

6. Order of steps

  1. Create the app jump-pogo on hosting.bloxity.io and copy its deploy token.
  2. Create the GitHub repo asivixlp44-cmyk/jump-pogo and add the secret LEGION_DEPLOY_TOKEN.
  3. Push the code to main. GitHub Actions builds and deploys it.
  4. After the first run: GitHub → Packages → jump-pogo-server → Change visibility → Public.
  5. Create the game on bloxity.io Manage Games with the details in section 1.
  6. Add the 17 IAP items from section 2.
  7. Set the webhook (section 3) and the server env vars (section 4), then redeploy.
