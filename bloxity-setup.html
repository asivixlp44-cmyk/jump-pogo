After you create the game

  1. Make a long random secret (any password generator). Put the same value in the webhook's secret if the IAP form asks for one, and in the server env var below.
  2. hosting.bloxity.io → app jump-pogo → environment:
    LEGION_WEBHOOK_SECRET
    <your secret> (turns off demo mode: purchases cost real Bux)
    SAVE_SECRET
    <another long random string> (signs progress backups)
  3. Bloxity sends each purchase to https://jump-pogo.host.bloxity.io/api/legion-webhook with the header x-legion-webhook-secret; the server only accepts it when the header matches LEGION_WEBHOOK_SECRET.
  4. Redeploy (push to main, or tell Claude), then buy one cheap item to test.
